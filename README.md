## The entry

Exactly one letter: **A** — coffee.

Coffee is the fuel that keeps an agent building through the night: the warung kopi at 3 a.m., the first sip before the first commit, the smell that says "one more round". Tea waits politely; coffee shows up.

## How it works

`main.ts` (Node 22 stdlib only) writes the single letter `A` to `/output/entry.txt` — UTF-8, exactly 1 character, no newline, no explanation, no punctuation.
